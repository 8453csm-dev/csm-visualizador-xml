# CSM Visualizador XML

Software Windows para visualização, conferência e apoio a rotinas fiscais com documentos XML.

## Versão estável

**CSM Visualizador XML 3.7.8**

Esta é a versão estável atualmente utilizada como base de distribuição para novas máquinas.

### Instalador completo

Arquivo oficial:

`CSMVisualizadorXML-3.7.8-Instalador-Completo.exe`

SHA-256:

`d6086b661fb40d4c05ce76d38ecec836a8ff7d5c4c55a6df35c68ed03b484b74`

O instalador completo contém todos os arquivos necessários e pode ser usado em um computador novo sem instalação anterior.

## Funcionalidades atuais

- Visualização de XML fiscal
- Localizador fiscal com Consulta DANFE e Meu DANFE
- Fluxo de CAPTCHA manual com retomada automática
- Download de XML/PDF quando disponível
- Conferência inteligente de devoluções por chave fiscal
- Backup e rollback durante atualização/instalação
- Atalhos no Windows e registro do aplicativo instalado

## Integridade

Antes de distribuir um instalador, confira o SHA-256 informado na pasta da respectiva versão.
